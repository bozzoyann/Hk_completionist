Où trouver ma sauvegarde ?

Les fichiers s'appellent user1.dat à user4.dat (un par emplacement de partie).

  • Windows %USERPROFILE%\AppData\LocalLow\Team Cherry\Hollow Knight
  • macOS ~/Library/Application Support/unity.Team Cherry.Hollow Knight
  • Linux / Steam Deck ~/.config/unity3d/Team Cherry/Hollow Knight
  • Steam Deck (Proton) ~/.local/share/Steam/steamapps/compatdata/367520/pfx/drive_c/users/steamuser/AppData/LocalLow/Team Cherry/Hollow Knight

Astuce Windows : collez le chemin dans la barre d'adresse de l'explorateur. Sur macOS : Finder → Aller → Aller au dossier (⇧⌘G).
